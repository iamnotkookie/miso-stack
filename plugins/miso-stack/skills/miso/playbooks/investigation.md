# Investigate a question

Use for: Explain a mechanism, establish a cause, or compare evidence.

You own the answer, not a change. A claim without a source or an observation is a guess, so label it as a guess.

## Procedure

1. Restate the question and name the evidence that would answer it. Keep a read-only request read-only.
2. Trace the relevant code and current state. Separate mechanics (what runs) from intent (why it was built that way). Missing history stays missing.
3. List competing hypotheses only where evidence is incomplete. Choose the probe that separates them.
4. Run safe probes and read their output. An empty search result does not prove that a behavior is impossible.
5. Answer with sources, limits, and the next experiment if uncertainty remains. When the question has a false premise, say so.

## Completion evidence

Cited code or recorded observations answer the question; unknowns are explicit.

## Reply

Lead with the answer. Cite a file and line or an observation for each claim. Label inference, and name what you could not establish.
