# Investigate a question

Use for: Explain a mechanism, establish a cause, or compare evidence.

## Procedure

1. Restate the question and identify the evidence that would answer it. Keep a read-only request read-only.
2. Trace the relevant code and current state. Separate mechanics from historical intent.
3. List competing hypotheses only where evidence is incomplete. Select a probe that distinguishes them.
4. Run safe probes and inspect their output. Do not treat an absent search result as proof that a behavior is impossible.
5. Give the answer with sources, limitations, and the next experiment if uncertainty remains.
