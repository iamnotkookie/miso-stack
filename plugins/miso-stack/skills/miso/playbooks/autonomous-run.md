# Run until a defined outcome

Use for: Execute one long task while the user is away.

## Procedure

1. Define the end condition, scope, resources, and authorization boundaries from the request.
2. Create a task plan and local trail. Work on the highest-risk unknown first.
3. Execute a small unit and check its real outcome.
4. Continue productive iterations. A repeat failure needs new evidence or a changed hypothesis.
5. Respect deployment, deletion, messaging, and project gates. Work on independent items when a gate blocks one path.
6. Stop on verified completion or a documented external blocker. Preserve a resumable handoff and do not label blocked work done.
