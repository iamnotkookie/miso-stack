# Write documentation

Use for: Create or correct a tutorial, how-to, reference, or explanation.

## Procedure

1. Identify the reader and the document purpose.
2. Read the actual behavior, available commands, and supported configuration.
3. Write a focused document using STE and Zinsser's principles. Link to separate document purposes.
4. Execute examples from their stated starting state in a sandbox.
5. Check paths, links, defaults, outputs, and recovery instructions against observed results.
6. Deliver the documentation with a clear statement of what was verified.

## Supporting skills

[miso-docs](../../miso-docs/SKILL.md), [miso-verify](../../miso-verify/SKILL.md)

## Completion evidence

A reader can follow the documented procedure and obtain the stated result.
