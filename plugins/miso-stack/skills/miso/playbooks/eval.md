# Evaluate agent behavior

Use for: Measure a prompt or skill change against explicit cases.

## Procedure

1. Freeze the baseline and candidate content.
2. Define case inputs and grading criteria before execution.
3. Run isolated cases and capture traces and resulting artifacts.
4. Grade observable behavior, including refused or out-of-scope actions.
5. Investigate failures without changing the expected behavior to fit the output.
6. Report sample count, actual harness and model selection, results, and limits.
