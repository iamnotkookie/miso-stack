# Pause with a usable handoff

Use for: Suspend work without losing state or proof.

## Procedure

1. Record the user's pause request and stop starting new work.
2. Collect or stop owned workers and processes at a safe point. Preserve other sessions.
3. Save current task state, pending changes, evidence, and failed experiments.
4. Record exact next commands, prerequisites, permissions, and unresolved decisions.
5. Check that evidence paths still exist and the handoff contains no credentials.
6. Report the paused state. Do not mark incomplete tasks done or resume without instruction.

## Supporting skills

[miso-plan](../../miso-plan/SKILL.md), [miso-trail](../../miso-trail/SKILL.md)

## Completion evidence

A new session can identify current state and resume without reconstructing lost context.
