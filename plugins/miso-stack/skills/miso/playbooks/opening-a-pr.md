# Prepare a focused pull request

Use for: Package an authorized change for review.

## Procedure

1. Read repository contribution rules and confirm the intended base and complete diff.
2. Run required checks and review the full change, including generated files and secrets.
3. Write a description of the problem, resulting behavior, and actual test evidence.
4. Prepare commits and a branch only when authorized. Do not initialize Git or add a remote as an implicit prerequisite.
5. Open or update the PR only within granted publication scope. Otherwise leave the description and patch ready.
6. Verify the created PR link and head revision when publication occurred. Do not invent a URL.

The review package accurately describes the full change and its executed checks.
