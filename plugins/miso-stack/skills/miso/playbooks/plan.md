# Plan verified work

Use for: Split a multi-phase change into dependent, checkable units.

## Procedure

1. Ground the target outcome and current state. Resolve the riskiest unknown first.
2. Define small tasks with dependencies, ownership, proof methods, and approval gates.
3. Write a plan using the bundled JSON contract. Run the plan checker.
4. Execute ready tasks in dependency order. Claim each task before work and attach real evidence when finishing.
5. Record failed experiments and blocked prerequisites. Continue independent tasks.
6. Verify the integrated result. Leave a resumable handoff for any unavailable environment.

[miso-plan](../../miso-plan/SKILL.md), [miso-trail](../../miso-trail/SKILL.md), [miso-verify](../../miso-verify/SKILL.md)

## Completion evidence

The plan is valid and each completed task has evidence; the final integration is checked separately.
