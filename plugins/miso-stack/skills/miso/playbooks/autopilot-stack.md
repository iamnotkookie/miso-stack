# Build a stack for later landing

Use for: Prepare an ordered sequence of dependent changes.

## Procedure

1. Define a small ordered set of changes and a verification method for each.
2. Use branches or commits only when Git work is authorized and a repository exists.
3. Build each change on the verified previous result.
4. Review each unit and verify the combined tip. Record the revision for every check.
5. Prepare review descriptions and dependency links. Keep publication within authorization.
6. Hand over the ordered stack with evidence. Do not land it when the request reserves that step for the user.
