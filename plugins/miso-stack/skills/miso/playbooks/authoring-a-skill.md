# Author a skill

Use for: Create or change a skill and prove its behavior.

## Procedure

1. Define the target behavior, triggers, negative cases, and scope.
2. Check for an existing capability before creating a new skill.
3. Write a compact procedure with references and tools where appropriate.
4. Validate names, frontmatter, links, scripts, and installed paths.
5. Run positive and negative sandbox cases through the intended harness.
6. Fix the observed failure cause and rerun affected cases. Document use and limitations.

## Supporting skills

[miso-author](../../miso-author/SKILL.md), [miso-eval](../../miso-eval/SKILL.md), [miso-docs](../../miso-docs/SKILL.md)

## Completion evidence

The skill loads and produces the intended behavior on representative sandbox cases.
