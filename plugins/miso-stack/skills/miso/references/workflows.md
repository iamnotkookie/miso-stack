# Workflow index

Use the eight default workflows for ordinary engineering work. Load a specialist workflow when the task requests that capability. Approval boundaries apply to all workflows.

| Workflow | Use | Selection |
| --- | --- | --- |
| [Investigate a question](../playbooks/investigation.md) | Explain a mechanism, establish a cause, or compare evidence. | Default |
| [Fix a defect](../playbooks/bug-fix.md) | Reproduce and repair incorrect behavior. | Default |
| [Build a feature](../playbooks/feature.md) | Add or change user-visible behavior. | Default |
| [Compare prototypes](../playbooks/prototype.md) | Resolve a design or behavioral uncertainty with executable alternatives. | Default |
| [Refactor safely](../playbooks/refactoring.md) | Change structure while preserving the agreed behavior. | Default |
| [Improve performance](../playbooks/performance.md) | Fix a specific measured performance problem. | Default |
| [Plan verified work](../playbooks/plan.md) | Split a multi-phase change into dependent, checkable units. | Default |
| [Write documentation](../playbooks/documentation.md) | Create or correct a tutorial, how-to, reference, or explanation. | Default |
| [Improve a metric repeatedly](../playbooks/hillclimb.md) | Run a bounded series of measured experiments. | Specialist |
| [Diagnose a live runtime](../playbooks/runtime-forensics.md) | Investigate leaks, CPU use, or intermittent behavior without assuming a fix. | Specialist |
| [Analyze a captured trace](../playbooks/trace-forensics.md) | Explain a profile, trace, heap snapshot, or crash artifact. | Specialist |
| [Verify visual equivalence](../playbooks/visual-parity.md) | Compare two UI implementations under matched conditions. | Specialist |
| [Author a skill](../playbooks/authoring-a-skill.md) | Create or change a skill and prove its behavior. | Specialist |
| [Evaluate agent behavior](../playbooks/eval.md) | Measure a prompt or skill change against explicit cases. | Specialist |
| [Bring a PR to review readiness](../playbooks/babysit.md) | Resolve CI failures, review findings, or conflicts on an existing PR. | Specialist |
| [Prepare and ship an approved change](../playbooks/shipping.md) | Verify a release or merge candidate before an authorized external action. | Specialist |
| [Run until a defined outcome](../playbooks/autonomous-run.md) | Execute one long task while the user is away. | Specialist |
| [Coordinate a multi-phase program](../playbooks/orchestrate.md) | Own dependent tasks across sessions or workers. | Specialist |
| [Process an independent work queue](../playbooks/autopilot-full.md) | Build and verify independent changes with explicit publication gates. | Specialist |
| [Build a stack for later landing](../playbooks/autopilot-stack.md) | Prepare an ordered sequence of dependent changes. | Specialist |
| [Resume prior work](../playbooks/session-pickup.md) | Continue from a handoff or prior task state. | Specialist |
| [Pause with a usable handoff](../playbooks/pause-safely.md) | Suspend work without losing state or proof. | Specialist |
| [Audit local runtime leftovers](../playbooks/worktree-cleanup.md) | Inspect worktrees or simulator resources before approved cleanup. | Specialist |
| [Prepare a focused pull request](../playbooks/opening-a-pr.md) | Package an authorized change for review. | Specialist |
