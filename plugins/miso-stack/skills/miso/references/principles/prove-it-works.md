# Prove it works

**Apply when:** You are about to say that a task is done.

**Rule:** Exercise the real artifact on the surface the user uses. A claim never stands in for runtime evidence.

**Why:** A wrong inference costs more than the check. Compile results, mocks, and agent reports are proxies.

- Run the feature and inspect the value at its source. A cache or a derived copy can be stale.
- An inconclusive result does not count. Neither does a check on a different surface from the user's.
- When a check surprises you, suspect the observation first.
- Prefer a script that a reviewer can rerun over a single inspection.
