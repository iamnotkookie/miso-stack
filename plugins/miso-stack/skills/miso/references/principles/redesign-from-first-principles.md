# Redesign from first principles

**Apply when:** A new requirement conflicts with the current design.

**Rule:** Ask what you would build if the requirement had existed on the first day. Compare that shape with the workaround.

**Why:** Each workaround hides the real design and makes the next requirement harder.

- Write both shapes in a few lines before you choose.
- Prefer the integrated shape. If its cost is outside the request, say so and name the follow-up.
