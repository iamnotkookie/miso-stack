# Attack the premise

**Apply when:** A second fix fails, two experiments fail the same way, or evidence conflicts with the request.

**Rule:** Stop patching. Write the assumption that the attempts share, and test that assumption directly.

**Why:** Another fix on a false assumption fails again and buries the real cause.

- Write the assumption as one sentence that an observation can prove false.
- Run the cheapest observation that can disprove it.
- When the assumption is false, revert what it motivated.
- When the false assumption came from the request, show the evidence and stop before you edit.
