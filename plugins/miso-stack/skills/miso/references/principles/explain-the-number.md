# Explain the number

**Apply when:** You take a measurement, or a measured result will shape a decision or a report. This includes evaluation scores.

**Rule:** Before you believe a number, find the bottleneck behind it. Confirm that the benchmark exercised the intended work.

**Why:** A number that nobody can explain is noise with the authority of data.

- Write the decision that each outcome would cause before you run.
- State the unit, the sample count, and the conditions.
- Report a null or negative result with the same care as a win.
